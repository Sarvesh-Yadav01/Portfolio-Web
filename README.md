# Sarvesh Yadav — Portfolio

A responsive personal portfolio showcasing my web development projects, technical skills, education, and certifications.

**Live portfolio:** [sarvesh-yadav01.github.io/Portfolio-Web](https://sarvesh-yadav01.github.io/Portfolio-Web/)

## About

I'm a Full Stack Web Developer and AI enthusiast completing a B.Tech in Computer Science and Engineering. This portfolio is built as a lightweight static website using HTML, CSS, and JavaScript, with no build tools or runtime dependencies.

## Highlights

- Responsive layout for desktop and mobile
- Light and dark themes, including system theme preference
- Project details with technology filters
- Skills and certifications sections
- Contact form that opens the visitor's email application
- Accessible navigation, reduced-motion support, and keyboard focus styles

## Run locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Sarvesh-Yadav01/Portfolio-Web.git
   cd Portfolio-Web
   ```

2. Open `index.html` in a browser. No installation or build step is needed.

## Deployment

The site is configured to deploy to GitHub Pages whenever changes are pushed to `main`. To enable it for this repository, open **Settings → Pages** and select **GitHub Actions** as the build and deployment source. After the workflow completes, the live site is available at:

<https://sarvesh-yadav01.github.io/Portfolio-Web/>
